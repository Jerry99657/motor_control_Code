# IMU 专项优化：标定、记录与回放流程

## 本阶段实现内容

本阶段把原先“上电时临时估计一次零偏”的方式扩展为可重复、可验证、可持久化的完整流程：

本阶段不需要修改 CubeMX；I2C1、系统时基、DMA 和中断配置均保持当前工程设置。

- MPU6500 继续以 100 Hz 采样，不改变 CubeMX 的 I2C 配置。
- `MPU6500 Data` 页面保留实时姿态、原始通道和趋势图。
- OK 键启动或取消静止快速标定。
- Right 键启动或停止 SD 原始数据记录。
- 标定结果写入 W25Q64 两个独立 4 KiB 扇区，采用序号、CRC32、写后回读和双副本切换，掉电时不会同时破坏新旧参数。
- 有有效持久化参数时，不再用原来的在线慢速学习持续改写陀螺仪零偏，从而保证同一组数据可重复分析。
- 首次使用且 W25Q64 尚无记录时仍保留原有启动标定；一旦存在有效记录，后续启动直接加载参数，并跳过约 1.6 秒的阻塞式启动标定。
- 提供 `tools/imu_replay.py`，可在电脑上完成解码、统计、航向重放、CSV 导出和可选绘图。

## W25Q64 分区变化

IMU 标定占用启动动画分区尾部原有的空闲空间：

| 地址 | 用途 |
|---|---|
| `0x000000..0x3FBFFF` | 启动动画 |
| `0x3FC000..0x3FCFFF` | IMU 标定副本 A |
| `0x3FD000..0x3FDFFF` | IMU 标定副本 B |
| `0x3FE000..0x3FFFFF` | 显示设置双副本 |

原有启动动画当前仍有约 30 KiB 余量。以后重新下载启动动画时，加载器会自动按新的分区边界检查长度，不会覆盖 IMU 参数。

## 板载静止标定方法

1. 将小车放在水平、稳定的地面上，电机停止，避免手碰车体。
2. 进入主菜单 `5 MPU6500 Data`。
3. 按 OK。页面状态先显示 `CAL keep still`，等待 0.8 秒消除放置扰动。
4. 状态变为 `CAL sampling` 后持续保持静止，进度从 0% 到 100%，采集 600 个有效样本，约需 6 秒。
5. 成功时显示 `CAL saved`，参数立即生效并保存到 W25Q64。

移动检测使用加速度模长和三轴角速度。如果标定过程中移动，当前数据会自动丢弃并重新等待；总计 30 秒仍无法取得稳定数据时显示运动超时。统计完成后还会检查三轴标准差，噪声过大时不会覆盖原有标定。

这是“车体水平静止标定”，主要解决零速陀螺偏置和安装平面上的 X/Y 加速度残差，不等同于六面加速度计标定。标定时车体倾斜会把倾角误认为安装偏置，因此必须尽量水平。

## SD 数据记录

在 `MPU6500 Data` 页面按 Right 开始记录，再按 Right 停止。离开页面也会自动刷新缓存、关闭文件并停止记录，防止后台占用 SD。

文件自动保存为：

```text
/IMU_LOG/IMU0001.IMU
/IMU_LOG/IMU0002.IMU
...
```

日志为小端序定长二进制格式。文件头 128 字节，包含格式版本、记录周期以及本次使用的标定参数；每条记录 84 字节，包含：

- 时间戳和采样序号；
- 原始三轴加速度、原始三轴陀螺仪、温度；
- 校准后的加速度与陀螺仪；
- Pitch、Roll、平面 Yaw 和 Yaw 角速度；
- 麦轮里程计 X/Y/航向；
- 四轮累计编码器位置；
- IMU I2C 累计读取失败次数。

写入使用 2016 字节缓存，正好容纳 24 条记录。100 Hz 下数据率约 8.4 KB/s，避免每个采样都发起一次小块 SD 写入。
记录过程中每 5 秒执行一次文件系统同步，降低意外断电时尚未落盘的数据量。标定和记录不能同时启动，确保一份日志始终使用同一组标定参数。

## 电脑端分析

把 SD 中的 `.IMU` 文件复制到电脑，然后在工程根目录执行：

```powershell
python tools/imu_replay.py D:\IMU0001.IMU
```

导出 CSV 和 JSON：

```powershell
python tools/imu_replay.py D:\IMU0001.IMU --csv D:\IMU0001.csv --json D:\IMU0001.json
```

安装 `matplotlib` 后可输出曲线图：

```powershell
python tools/imu_replay.py D:\IMU0001.IMU --plot D:\IMU0001.png
```

脚本默认只依赖 Python 标准库。它会输出实际采样率、周期抖动、超过 30 ms 的间隙、序号丢失、静止样本比例、校准后三轴均值/标准差、加速度模长、航向漂移、I2C 失败增量等信息。脚本还按固件相同的 Z 轴方向、零偏、0.1 dps 死区和梯形积分重放平面航向，并计算与固件记录航向的 RMS 差异。

## 推荐测试数据集

每次算法修改后至少记录以下四组数据，文件名可在复制到电脑后重命名：

1. `static_5min`：水平静止 5 分钟，检查零偏噪声和 Yaw 漂移。
2. `rotate_cw_ccw`：原地顺时针、逆时针各转数圈，检查方向、比例和回零误差。
3. `straight_x_y`：X/Y 各直行约 1 米，比较 IMU 航向与编码器里程计。
4. `vibration`：电机运行但车轮离地，观察机械振动是否误触发姿态修正。

日常使用不需要手工导出数据；板载标定完成后即可使用。只有在继续调节滤波、航向闭环或排查特定漂移时，才需要把相应 `.IMU` 日志复制到电脑运行分析脚本。
